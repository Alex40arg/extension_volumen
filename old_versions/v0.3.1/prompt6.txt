# 9. Sentido de los sliders

Comportamiento intuitivo:

* arriba = gain positivo;
* centro = 0 dB;
* abajo = gain negativo.

Visualmente debe quedar claro que:

```text
top    = +12 dB
center = 0 dB
bottom = -12 dB
```

Si `<input type="range">` requiere transformación CSS para orientación vertical, implementarlo de forma robusta.

No alterar los valores internos del EQ.
