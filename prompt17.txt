## OBJETIVO GENERAL

Quiero ordenar primero el versionado actual y luego recuperar dos mejoras de interfaz que se perdieron al restaurar la antigua v0.8 desde el experimento v0.9:

* la raíz actual volvió a partir de v0.8, pero después recibió correcciones y mejoras nuevas, incluyendo los iconos dinámicos ON/OFF.

No modificar ni sobrescribir:

```text
old_versions/v0.8/
old_versions/v0.9/
```

Ambos deben conservarse intactos como historial.

## Convertir el estado ACTUAL en v1.0

Antes de hacer cualquier cambio de interfaz:

1. considera el estado actual de la raíz como **v1.0 estable**;
2. actualiza el número de versión correspondiente a:

```text
1.0.0
```

si actualmente todavía figura como `0.8.0`;

3. actualiza referencias explícitas a la versión actual en README/log solamente si corresponde;
4. no cambies ninguna funcionalidad durante este paso.

Luego crear un snapshot completo:

```text
old_versions/v1.0/
```

Debe contener una copia exacta del estado estable actual.

No copiar `old_versions/` recursivamente dentro del snapshot.

No sobrescribir `old_versions/v1.0/` si ya existiera: en ese caso detenerse e informar.

Este snapshot v1.0 debe incluir el estado actual funcionando, incluyendo:

## Al pulsar `Save preset`

Transformar temporalmente esa misma zona en:

```text
NAME     [ campo de texto ]

[ Save ] [ Cancel ]
```

Comportamiento:

* ocultar temporalmente el selector;
* mostrar un input en exactamente el mismo lugar;
* cambiar `PRESET` por `NAME`;
* reutilizar el botón `Save preset` como `Save`;
* reutilizar `Rename` como `Cancel`;
* ocultar `Delete` durante la edición;
* dar foco automáticamente al campo de nombre;
* no agregar otra fila;
* no aumentar la altura del panel.

Preferir mantener selector e input dentro del mismo contenedor y alternar visibilidad mediante `hidden`, clases CSS o equivalente.
