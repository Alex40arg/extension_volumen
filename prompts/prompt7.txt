# 2. Separar configuración de EQ y sesión DSP

Actualmente, al apagar `Audio Processing`, la sesión de audio se destruye y el EQ vuelve visualmente a Flat.

Quiero cambiar ese comportamiento.

La configuración elegida por el usuario debe tratarse como un estado separado del procesamiento activo.

Conceptualmente debe existir por pestaña algo equivalente a:

```text
Tab settings:
    eqEnabled
    eqBands[7]
    selectedPreset
```

separado de:

```text
Active audio session:
    stream
    AudioContext
    nodes
    masterGain
    mute
```

No es obligatorio usar exactamente estas estructuras, pero sí preservar esa separación conceptual.

---

# 3. Comportamiento al apagar Audio Processing

Ejemplo inicial:

```text
Volume: 135%
EQ: ON

30 Hz   +4
90 Hz   +3
300 Hz  -1
1 kHz   -3
3 kHz   -1
8 kHz   +2
15 kHz  +4
```

El usuario apaga:

`Audio Processing → OFF`

Resultado esperado:

* el stream se detiene;
* la sesión DSP se destruye;
* el audio normal del navegador vuelve inmediatamente;
* el master volume de la próxima activación NO debe conservar 135%;
* la curva EQ permanece almacenada para esa pestaña;
* el estado EQ ON/OFF permanece almacenado;
* el popup debe seguir mostrando visualmente la curva anterior aunque Audio Processing esté OFF.

Los controles EQ pueden quedar deshabilitados mientras Audio Processing está OFF si esa sigue siendo la UX actual, pero sus posiciones deben conservarse.

---

# 4. Comportamiento al volver a activar Audio Processing

Siguiendo el ejemplo anterior:

Cuando el usuario vuelve a activar Audio Processing:

```text
Volume → 100%
Mute → OFF

EQ → ON
30 Hz   +4
90 Hz   +3
300 Hz  -1
1 kHz   -3
3 kHz   -1
8 kHz   +2
15 kHz  +4
```

Por lo tanto:

* el master volume SIEMPRE vuelve a 100% por seguridad auditiva;
* Mute vuelve OFF;
* el EQ recupera su estado anterior;
* la curva EQ anterior se reaplica;
* no debe producirse un pico súbito de volumen.

Esta diferencia es deliberada:

```text
Master volume → NO persistir tras OFF
EQ settings   → SÍ persistir durante la vida de la pestaña
```

# 21. Arquitectura

`Audio Processing OFF`

# 22. Seguridad auditiva

Mantener como regla absoluta:

Cada nueva sesión de Audio Processing comienza con:

```text
master gain = 1.0
Volume = 100%
Mute = OFF
```

Aunque anteriormente la pestaña tuviera:

```text
Volume = 180%
```

NO recordar ese valor después de apagar Audio Processing.

EQ sí puede recuperarse porque es una configuración tonal distinta al master amplification.
